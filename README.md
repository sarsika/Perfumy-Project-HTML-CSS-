# Perfumy – Perfume Website 🌸

A responsive perfume website built using HTML and CSS.  
This project showcases a modern product landing page with elegant UI design and clean layout.

## 🚀 Features
- Responsive design for all devices
- Clean and modern UI
- Product showcase section
- Simple and beginner-friendly code

## 🛠️ Technologies Used
- HTML5
- CSS3

## 📂 Project Structure
- index.html – Main webpage
- style.css – Styling file
- perfume1.jpg, perfume2.jpg, perfume3.jpg – Product images

## 🎯 Purpose
This project was created to practice front-end web development skills and understand layout design using html and css.
